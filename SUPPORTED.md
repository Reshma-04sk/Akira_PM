# Supported Versions and Support Lifecycle

This document describes the support policy for different releases of Akira-PM.

## Supported Versions

Only the latest major and minor releases are actively supported with bug fixes, performance improvements, and security patches.

| Version | Release Date | Support Level | Security Updates |
|:---|:---|:---|:---|
| `1.3.x` | Aug 2026 | Active Support | Yes |
| `1.2.x` | May 2026 | Maintenance | Yes |
| `1.1.x` | Feb 2026 | EOL | No |
| `1.0.x` | Nov 2025 | EOL | No |

## Release Support Types

- **Active Support**: We actively investigate reports, backport non-breaking bug fixes, release performance patches, and issue security advisories.
- **Maintenance**: Only critical security vulnerabilities and severe data corruption issues will be patched.
- **End of Life (EOL)**: No updates of any kind will be provided. Users are strongly recommended to upgrade to a supported release.
