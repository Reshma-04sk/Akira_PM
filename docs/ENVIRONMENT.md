# Environment Variables Guide

This document lists all environment variables used in Akira-PM.

---

## 1. Backend Core Settings

The FastAPI application loads settings from files named `.env.[ENV_STATE]` located in the workspace root.

| Key | Required | Default (Dev) | Description |
| :--- | :---: | :--- | :--- |
| `ENV_STATE` | Yes | `development` | Environment state: `development`, `testing`, `production`. |
| `APP_NAME` | No | `Akira-PM` | Metadata title in Swagger UI documents. |
| `BACKEND_PORT` | No | `8000` | Local web server listening port. |
| `BACKEND_LOG_LEVEL` | No | `info` | Logs verbosity (`debug`, `info`, `warning`, `error`). Logs are formatted in JSON format when running in production mode. |
| `BACKEND_SECRET_KEY` | Yes | `dev_secret_key...` | Cryptographic secret used to sign JWTs. Must be a secure 32-character random string in production. |
| `BACKEND_ACCESS_TOKEN_EXPIRE_MINUTES` | No | `30` | JWT access token lifespan before rotation. |

---

## 2. Database & Cache Connection Settings

| Key | Required | Default (Dev) | Description |
| :--- | :---: | :--- | :--- |
| `POSTGRES_USER` | Yes | `saas_admin` | DB username (fallback if `DATABASE_URL` is omitted). |
| `POSTGRES_PASSWORD` | Yes | `saas_password_dev`| DB password. |
| `POSTGRES_HOST` | Yes | `localhost` | Database host. |
| `POSTGRES_PORT` | No | `5432` | Database port. |
| `POSTGRES_DB` | Yes | `saas_db` | Database name. |
| `DATABASE_URL` | No | *[Autogenerated]* | Connection URL overrides individual parameters. Protocol must start with `postgresql+asyncpg://`. |
| `REDIS_URL` | No | `None` | Upstash Redis connection string. Caching and rate-limiting fall back to memory if omitted. |

---

## 3. Frontend Settings

Vite parses configurations with `VITE_` prefix and embeds them into built assets.

| Key | Required | Default (Dev) | Description |
| :--- | :---: | :--- | :--- |
| `VITE_API_URL` | Yes | `http://localhost:8000/api/v1`| Target backend REST API URL. |
| `VITE_PORT` | No | `5173` | Local Vite dev server port. |

---

## 4. Configuration Templates

### Local Development Setup (`.env.development`)
```ini
ENV_STATE=development
APP_NAME="Akira-PM (Dev)"
BACKEND_PORT=8000
BACKEND_LOG_LEVEL=debug
BACKEND_SECRET_KEY=dev_secret_key_placeholder_do_not_use_in_prod_12345
BACKEND_ACCESS_TOKEN_EXPIRE_MINUTES=60

POSTGRES_USER=saas_admin
POSTGRES_PASSWORD=saas_password_dev
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=saas_db

VITE_API_URL=http://localhost:8000/api/v1
VITE_PORT=5173
```
