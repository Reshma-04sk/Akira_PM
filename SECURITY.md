# Security Policy

We take the security of Akira-PM seriously. This document describes security update cycles and how to report vulnerabilities.

---

## 1. Supported Versions

Security updates are actively backported to the following release tags:

| Version | Supported |
| :--- | :---: |
| `1.0.x` | Yes |
| `< 1.0.0` | No |

---

## 2. Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you discover a potential vulnerability, please report it privately:
1. Email your findings to: `security@akira-pm.com`
2. Include the following details in your report:
   - Vulnerability type (e.g., Remote Code Execution, Privilege Escalation)
   - Step-by-step instructions (or PoC script) to reproduce the issue
   - Potential impact on users or database nodes
3. You will receive an acknowledgment receipt within 48 hours.
4. We will coordinate a fix and release a security advisory within 30 days.
